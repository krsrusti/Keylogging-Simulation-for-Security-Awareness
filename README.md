## Lumberjack
Educational Keylogger for Cybersecurity Awareness

## Problem Statement
Keyloggers are common malware used for credential theft.
Security professionals must understand how they work to defend against them.

## Objective
To simulate a basic keylogging attack in a controlled environment
and study its behavior for defensive security learning.

## Tech Stack
Python
pynput
OS-level input handling

## Features
Captures keystrokes
Logs data locally
Runs in a controlled test environment

## Security & Ethical Considerations
No data exfiltration
No persistence mechanisms
For lab/testing use only

## What Security Teams Can Learn
How keyloggers capture input
Indicators of compromise (IoCs)
How antivirus tools detect such behavior
Why least-privilege matters
